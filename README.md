# Funngro Website Revamp (Beginner HTML/CSS/JavaScript)

## Project pages
- `index.html` — homepage / navigation landing page
- `company.html` — dedicated Company landing page
- `teen.html` — dedicated Teen landing page
- `styles.css` — shared responsive styling
- `script.js` — mobile navigation interaction
- `SEO-AUDIT-REPORT.md` — starter SEO audit and verification checklist

## Run locally
1. Download and unzip the project.
2. Open `index.html` in Chrome, Edge, or Firefox.
3. Use the navigation to visit Company and Teen pages.
4. Resize the browser or use mobile device preview to test responsiveness.

## Publish free with GitHub Pages
1. Create/sign in to a GitHub account.
2. Create a new public repository, e.g. `funngro-revamp`.
3. Upload all files to the repository root.
4. Open **Settings → Pages**.
5. Under Build and deployment, choose **Deploy from a branch**, select `main` and `/ (root)`, then Save.
6. Wait for the published URL shown in the Pages settings.
