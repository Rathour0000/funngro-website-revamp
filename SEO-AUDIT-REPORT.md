# Funngro Website SEO Audit — Starter Report

**Prepared:** 31 October 2026  
**Project:** Funngro Website Revamp  
**Scope:** Preliminary audit framework and recommendations. This is not a completed technical crawl; verify each finding against the live website before submitting it as a factual issue.

## 1. Executive summary
The revamp concept targets two important audiences: companies seeking project support and teens seeking practical experience. The proposed page structure separates these journeys, uses descriptive headings, includes clear calls to action, and is designed responsively.

## 2. Target audience and keyword ideas
| Page | Primary keyword idea | Supporting keyword ideas |
|---|---|---|
| Company | hire young talent | teen talent platform, project-based talent, fresh ideas for business |
| Teen | projects for teens | teen skill development, learn through projects, student opportunities |
| Home | Funngro | Funngro for companies, Funngro for teens |

Validate search demand and intent with Google Keyword Planner or Search Console before prioritizing keywords. Avoid keyword stuffing.

## 3. On-page SEO recommendations
- Give every page a unique, descriptive title and meta description.
- Use one clear H1 per page and organize supporting content with H2/H3 headings.
- Write original copy that answers the audience's questions.
- Use descriptive internal-link text such as “Explore company projects”.
- Add descriptive alt text to meaningful images; use empty alt text for decorative images.
- Add canonical URLs after the final production URLs are known.
- Add Open Graph metadata for better social sharing previews.

## 4. Technical SEO checklist
- Confirm HTTPS is enabled and HTTP redirects to HTTPS.
- Check robots.txt and XML sitemap availability.
- Verify indexability and canonical tags for all intended landing pages.
- Test mobile usability and Core Web Vitals in PageSpeed Insights.
- Compress images and use modern formats such as WebP/AVIF.
- Avoid layout shifts; reserve image dimensions.
- Check 404 pages, redirect chains, and broken internal links.
- Add structured data only where the page content genuinely qualifies (for example, Organization or WebSite).

## 5. Content and trust recommendations
- Explain the platform's process clearly for both companies and teens.
- Provide transparent eligibility, safety, supervision, payment, and support information where applicable.
- Use genuine testimonials and case studies only with permission.
- Keep claims about outcomes, earnings, and participant numbers accurate and substantiated.
- Make contact and help information easy to find.

## 6. Measurement plan
Track organic clicks, impressions, CTR, and average position in Google Search Console. Use analytics to measure engaged sessions and meaningful actions such as company enquiries and teen registrations. Compare performance before and after launch over consistent periods.
